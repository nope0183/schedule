# 📅 Бот расписания занятий

Автоматизированный бот для парсинга и предоставления актуального расписания занятий.
Ни единой строчки кода не написано вручную, кроме этой
Проект сделанный 4 ии агентами за 1 вечер
## 📖 Описание

Этот проект представляет собой систему автоматического получения и обработки расписания занятий с сайта образовательного учреждения. Бот регулярно проверяет изменения в расписании, парсит данные из Excel-файла и предоставляет их в удобном JSON-формате.

## ✨ Возможности

- **Автоматическое обновление** — проверка изменений в расписании по хешу файла
- **Парсинг Excel** — извлечение данных из `.xlsx` файлов с сайта
- **Поддержка групп** — обработка расписания для множества учебных групп
- **6 пар в день** — полное покрытие учебного дня (пары 1-6)
- **Информация о занятиях**:
  - 📚 Предмет
  - 👨‍🏫 Преподаватель
  - 🚪 Аудитория
- **Поддержка подгрупп** — корректное отображение занятий для разделённых групп
- **Дата в русском формате** — красивое отображение даты с днём недели

## 🛠 Технологии

- **Python 3.x**
- **requests** — загрузка файлов с сервера
- **openpyxl** — парсинг Excel файлов
- **hashlib** — отслеживание изменений файлов
- **JSON** — хранение результата

## 📊 Формат выходных данных

Файл `schedule.json` содержит следующую структуру:

```json

  "date": "1 сентября 2025, понедельник",
  "groups": ["1161", "1162", "1163"],
  "schedule": {

      {

        "room": "23"
      }

  }

```

## ⚙️ Как это работает

1. **Скачивание файла** — скрипт загружает `rasp1.xlsx` с сервера
2. **Проверка изменений** — вычисляется MD5-хеш и сравнивается с сохранённым
3. **Парсинг Excel**:
   - Извлекается дата из названия листа
   - Определяются учебные группы (строка 2, колонки B-AK)
   - Извлекаются данные по 6 парам (координатная структура)
4. **Обработка данных**:
   - Разбор объединённых ячеек
   - Поддержка подгрупп (разделение на несколько записей)
   - Извлечение предмета, преподавателя и аудитории
5. **Сохранение результата** — запись в `schedule.json` и обновление хеша

## 🎯 Особенности парсинга

- **Умное определение даты** — из названия листа или содержимого ячеек
- **Обработка объединённых ячеек** — корректное чтение данных из merged-диапазонов
- **Поддержка подгрупп** — отображение всех вариантов через разделитель ` / `
- **Русская локализация** — месяцы и дни недели на русском языке
